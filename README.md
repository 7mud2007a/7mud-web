# DANIEL — Creative Developer & Digital Creator Portfolio

A high-end, cinematic, personal portfolio website built with pure HTML5, CSS3, and Vanilla JavaScript. Designed with a luxury frosted glass system, interactive 3D crystal gemstone "D" visual, English and Arabic localization, dark/light theme switching, and smooth scroll interactions.

## ✨ Key Features

1. **Frosted Glass Design System**
   - Translucent backgrounds, inner highlights, thin glass borders, soft ambient glows, and clean depth.
2. **Interactive Crystal Gemstone "D"**
   - Custom WebGL/Canvas 2D 3D gemstone rendering that subtlely reacts to mouse movement and fades upwards as you scroll into the portfolio.
3. **Floating Bottom Navigation**
   - Smoothly hides on scroll down, reappears on scroll up or at the top of the page.
   - Animated sliding active indicator pill.
4. **Bilingual Localization (EN / AR)**
   - English (default) and Arabic support.
   - Dynamic layout direction switching (`dir="rtl"` and `lang="ar"`).
5. **Dark / Light Mode Toggling**
   - Persisted in `localStorage`.
   - Uses professional inline SVG icons (no cheap Unicode characters).
6. **Editorial Selected Work Layout**
   - Cinematic project presentation with project links, categories, staggered reveal animations, and glass hover reflections.
7. **Zero Framework Dependencies**
   - Built pure with HTML5, CSS3, and Vanilla JavaScript.
   - Mobile, tablet, and desktop responsive.

## 🚀 Local Development & Deployment

### Running Locally
You can serve the static files with any standard HTTP server (e.g. Python, Node.js, or Live Server):

```bash
# Using Python 3:
python3 -m http.server 8080
```
Then visit `http://localhost:8080` in your web browser.

### Deploying to Render / GitHub Pages / Vercel
This repository is pre-configured as a static website. You can connect this repository directly to Render, GitHub Pages, or Netlify with `index.html` at the root level.
