# DANIEL — Creative Developer Portfolio

To replace portfolio images, simply replace the files inside `/assets/images/` using the same filenames:

- `assets/images/profile-placeholder.jpg`
- `assets/images/project-01-placeholder.jpg`
- `assets/images/project-02-placeholder.jpg`
- `assets/images/project-03-placeholder.jpg`
- `assets/images/project-04-placeholder.jpg`
- `assets/images/hero-placeholder.jpg`

No code changes should be necessary when you replace the images with files using the same names.

## Redesign Overview

A high-end studio digital portfolio built with clean visuals, motion, interactive glass design, and seamless internationalization.

### Tech Stack
- **HTML5** (Semantic structure, accessibility, inline SVGs)
- **CSS3** (Custom Frosted Glass Design System, Responsive Media Queries, CSS Variables)
- **Vanilla JavaScript** (Theme persistence, AR/EN RTL support, Scroll & Cursor animations)

### Features
- **Intro Experience:** Premium static crystal "D" loader with animated loading indicators.
- **Floating Bottom Nav:** Liquid glass pill navigation that smoothly auto-hides when scrolling down and reappears when scrolling up.
- **Glass Design System:** Subtle translucency, thin borders, inner highlights, and light reflection glares without heavy blur or cheap gradients.
- **Cinematic Work Showcase:** Editorial case studies for selected projects (Garaue Chocolate, Biz AI, EDGE AI Trader, Creative Lab).
- **Internationalization (i18n):** English and Arabic (RTL layout switch) without page reloads.
- **Theme Switcher:** Dark mode and Light mode support with preference saved in `localStorage`.
